# ChatGPT Memory Dreaming 2026

## Source Metadata

- Source: OpenAI, [Dreaming: Better memory for a more helpful ChatGPT](https://openai.com/index/chatgpt-memory-dreaming/)
- Published: 2026-06-04
- Access note: public official product/research post

## Summary

OpenAI announced a more capable and compute-efficient system for synthesizing ChatGPT memory across many conversations and long time horizons. OpenAI calls the background memory-curation method "dreaming" and frames the 2026 update as a response to three practical problems: memory becoming stale, memory being wrong or irrelevant, and memory needing to scale across hundreds of millions of users with multi-year histories.

The important shift is not simply "more things remembered." OpenAI is treating memory as an actively maintained context layer that should carry forward useful facts, follow preferences and constraints, and update as time passes.

## What OpenAI Says Changed

- Saved memories launched in April 2024 and depended heavily on explicit cues to remember information.
- In April 2025, ChatGPT gained a first version of dreaming that could automatically curate memory from chat history.
- The 2026 architecture is intended to be more capable, more scalable, and more compute-efficient.
- Synthesized memories are reviewable through a visible memory summary where users can correct, dismiss, add, or update information.
- OpenAI says recent improvements reduced the compute required to serve dreaming to Free users by about `5x`.
- The update began rolling out to Plus and Pro users in the United States on 2026-06-04, with additional countries and Free and Go users planned over the following weeks.

## Why It Matters

Memory is becoming infrastructure for long-running assistance rather than a personalization extra. A useful assistant needs more than a large context window inside one chat. It needs a way to preserve relevant context across chats, revise stale assumptions, and expose enough of that memory for the user to inspect and correct it.

This fits the [Computer Work Agent](../concepts/computer-work-agent.md) pattern. Durable personal context can reduce the repeated setup cost of complex projects, but it also raises the importance of user controls, correction, privacy, and explicit written rules.

## Do Not Overclaim

- Do not treat synthesized memory as perfect recall or a factual record of the user.
- Do not assume a larger or more active memory system is always better; stale, incorrect, or over-personalized context can make assistance worse.
- Do not treat memory as a replacement for checked-in project instructions, source trails, or public records.
- Do not collapse product memory into human memory, identity, consciousness, or personhood.
- Do not describe the rollout as globally available on 2026-06-04; OpenAI said it began with Plus and Pro users in the United States.
