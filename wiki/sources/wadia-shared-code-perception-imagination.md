# Wadia Shared Code For Perception And Imagination

This source note covers Varun S. Wadia and colleagues' 2026 *Science* paper, "A shared code for perceiving and imagining objects in human ventral temporal cortex," plus local supplementary materials saved as `raw/neurons-imagination.pdf`.

## Metadata

- Main paper: Wadia et al., "A shared code for perceiving and imagining objects in human ventral temporal cortex"
- Journal: *Science*
- Citation: *Science* 392, 207-215 (2026)
- DOI: <https://www.science.org/doi/10.1126/science.adt8343>
- Local raw file: `raw/neurons-imagination.pdf`
- Raw-file note: the local PDF is supplementary material, not the full article and not the Nature Neuroscience "Neurons for seeing and imagining" highlight.

## Core Finding

The study provides rare single-neuron evidence that seeing an object and imagining that object use overlapping neuronal code in human ventral temporal cortex.

The careful version:

- the researchers recorded from neurons in ventral temporal cortex in 16 epilepsy patients with implanted electrodes;
- participants viewed many object images, then performed cued imagery tasks;
- many neurons were tuned to axes in a low-dimensional object-feature space derived from deep neural network representations;
- around 40% of axis-tuned neurons reactivated during imagery in the Nature Neuroscience highlight's summary;
- this supports a shared code for perception and imagery, not a total identity between seeing and imagining.

## Why It Matters Here

This is a strong update for [Perception And Imagination Overlap](../concepts/perception-and-imagination-overlap.md).

The existing Dijkstra/Fleming reality-threshold lane says perception and imagination may contribute to a shared subjective signal, and the brain has to judge whether an experience should count as real.

Wadia et al. adds a lower-level bridge:

> Some of the same object-coding neurons and feature axes involved in seeing objects are reactivated when people imagine them.

That makes the skull-custard picture less metaphorical. The brain is not running imagination in a totally separate theatre. It can partially reuse the machinery of perception.

## Relation To Reality Threshold

This does not replace [Reality Threshold](../concepts/reality-threshold.md). It strengthens the setup.

If perception and imagination can share object-level neural code, then the brain needs mechanisms for source monitoring and reality judgment:

- is this signal externally driven?
- is it internally generated?
- how vivid is it?
- how much sensory confidence does it carry?
- should it be treated as real, imagined, remembered, dreamed, intrusive, or hallucinatory?

Dijkstra/Fleming gives one model of that classification problem. Wadia et al. gives single-neuron support for why the classification problem exists in the first place.

## Relation To Predictive Processing And Generative Models

The paper also belongs near predictive-processing language. Berkeley's report frames the finding as evidence that seeing and imagining use the same code, while the Simons Foundation write-up explicitly connects the result to generative-model ideas.

Safe synthesis:

- perception is not a camera dump;
- imagery is not magic private theatre;
- both can involve reusing generative object representations;
- reality monitoring depends on how internally generated representations are distinguished from externally driven ones.

This is not "the brain is literally a text-to-image model." It is a useful computational rhyme: generative systems can reconstruct or simulate sensory-like content from learned latent structure.

## Caveats

- The participant group was medically specific: epilepsy patients with implanted electrodes.
- The main task used static, grayscale, two-dimensional object images.
- The imagery task involved cued imagery of recently viewed stimuli, not arbitrary imagination.
- The study concerns object representations in ventral temporal cortex, not all perception, all imagination, or all conscious experience.
- Shared code does not mean imagined objects are normally as strong, reliable, or reality-classified as perceived objects.
- Do not use this as evidence that imagination creates external reality. Behave yourself.
