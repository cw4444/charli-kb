# Zhao et al. - Thalamus-Brainstem History-Biased Decisions

Shan Zhao and colleagues published *A thalamus-brainstem attractor network drives history-biased decisions* in *Nature* on 2026-06-10.

## Access Note

Nature marks the article closed/hybrid access, not open access. The publisher exposes the complete abstract, metadata, references, figure previews, and a citation to a Zenodo code release, but not public full text. This public wiki note therefore stays within the abstract/metadata boundary.

## Core Claim

The paper asks how a recent event persists long enough to bias a later decision, without simply overwhelming current sensory evidence.

In larval zebrafish performing memory-guided evasive manoeuvres, the authors used whole-brain cellular-resolution imaging, optogenetic manipulation, and a whole-brain computational model. The public abstract describes a hierarchical attractor-integrator architecture:

- **Dorsal-thalamus discrete attractors** encoded the location of the most recent obstacle as persistent, categorical neural activity lasting roughly 10–20 seconds.
- Manipulating the dorsal thalamus optogenetically could abolish or impose the animal's serial bias, supporting a causal role rather than a passive memory correlate.
- A downstream **hindbrain integrator** combined the thalamic recent-event signal with current sensory cues, generating a graded signal that reflected multi-trial history and biased the next action.
- The computational model recapitulated behaviour and predicted a role for heterogeneous inhibitory subtypes in flexible transitions between network states.

The useful translation is not "the fish ignores present evidence." It is that current choice can be computed from present input plus a structured, short-lived memory of what just happened.

## Why It Matters Here

This is a mechanism-shaped companion to [Practical Agency Inside Constraint](../concepts/practical-agency-inside-constraint.md). An agent can be sincerely responding to current evidence while its current state already carries a history-dependent prior. The prior is not necessarily irrational; in slowly changing environments it can be adaptive. The problem appears when the environment changes faster than the persistence mechanism expects.

It also strengthens the wiki's broader state-sensitive perception/action warning: decisions do not begin on a clean blank trial. Recent events can alter the starting state, what is weighted, and the next reachable action before deliberation gets its paperwork in order.

## Do Not Overclaim

- This is larval-zebrafish evidence from a specific evasive-navigation task, not direct proof about human judgment, personality, trauma, politics, investing, or everyday free will.
- A 10–20-second categorical memory in fish is not a complete model of autobiographical memory or long-term habits.
- Serial dependence can be adaptive in temporally correlated environments; it is not automatically bias in the pejorative sense.
- The abstract supports a thalamus-to-hindbrain hierarchy in this task, not a universal decision architecture for all animals.
- Attractor models are useful mechanistic hypotheses, not a licence to call any persistent thought an attractor and go for lunch.
